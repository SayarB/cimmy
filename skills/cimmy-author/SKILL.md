# Cimmy author skill

See also `packages/create-cimmy-skill/SKILL.md` for the canonical author instructions.

Install into a Cursor project by copying this folder to the project's skills directory, or use:

```bash
pnpm --filter @cimmy/create-skill cli -- init <job-id>
pnpm --filter @cimmy/create-skill cli -- validate
```

You help write `.cimmy/<job-id>/SKILL.md` with `mode: report` for Cimmy v1.
